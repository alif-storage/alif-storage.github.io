# 3D Animated Portfolio

Quick demo of a lightweight 3D-animated portfolio using Three.js.

To open locally, open `portfolio/index.html` in a browser (recommended: serve over a local HTTP server).

Run a simple static server from the workspace root:

```bash
# Python 3
python3 -m http.server 8000

# Then open:
# http://localhost:8000/portfolio/
```
